
# Data Visualization & Analytics Platform

A modern web application for creating, analyzing, and sharing interactive data visualizations with AI-powered insights.

## 🌟 Features

### Data Visualization
- Advanced interactive charts and graphs
- Real-time data updates
- Customizable visualization options
- Responsive design for all devices

### AI Integration
- Perplexity AI-powered data analysis
- Intelligent insights generation
- Interactive AI chat assistant
- Data pattern recognition

### Collaboration Tools
- User profiles and authentication
- Direct messaging system
- Friend connections
- Chart sharing capabilities
- Interactive forum discussions

## 🛠️ Technology Stack

### Frontend
- React with TypeScript
- Framer Motion for animations
- TanStack Query for data fetching
- Tailwind CSS with Shadcn UI
- D3.js for data visualization
- Wouter for routing

### Backend
- Express.js server
- PostgreSQL with Drizzle ORM
- Passport.js authentication
- WebSocket for real-time features

## 💻 Development

The application uses Vite for development with hot module replacement:

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Server runs on port 3001 and supports:
- API endpoints for data management
- Real-time WebSocket connections
- User authentication flows
- File uploads and processing

## 🏗️ Project Structure

```
├── client/          # Frontend React application
├── server/          # Express backend server
├── db/              # Database schemas and migrations
```
